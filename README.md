# K‑VLSI Training Program – Hands‑On Repository

This repository contains all hands-on learning materials, project implementations, and simulation exercises completed during the K‑VLSI Front-End VLSI Training Program, focusing on RTL Design, Digital System Design, Verification, and Communication Protocols.

The projects were implemented using Verilog, SystemVerilog, and UVM, with simulations run on Vivado and EDA Playground.

## Repository Contents

1. Digital System Design using Verilog  
   Module-level Verilog implementations of core digital circuits: logic gates, adders, multiplexers, decoders, flip-flops, counters, and FSMs. Simulated using Vivado.

2. Verilog Programs  
   Concept-based Verilog examples showing dataflow, gate-level, and behavioral modeling: arithmetic circuits, control logic, state machines. Simulated using EDA Playground (simulation links embedded).

3. SystemVerilog Programs  
   SystemVerilog-based design constructs using logic, interface, typedef, structures, enums, and assertions.

4. SV Testbench Architecture Programs  
   Demonstrates SystemVerilog testbench components such as interface, driver, monitor, scoreboard, and constrained random stimulus generation.

5. UVM Programs  
   Covers UVM testbenches including classes like uvm_test, uvm_env, uvm_agent, uvm_sequence, configuration DB, factory usage, and scoreboarding.

6. I2C Protocol Project  
   A complete RTL + Verification project implementing Single-Master Multi-Slave I2C Protocol using Verilog and SystemVerilog. Includes:
   - I2C master-slave architecture
   - Start/Stop signal handling
   - Acknowledgement mechanism
   - Read/Write operations
   - Integrated SV-based testbench
   - Functional coverage collection and assertions
   - Simulated using EDA Playground

## Tools & Platforms Used

- Vivado – RTL design and simulation (used for Digital System Design)
- EDA Playground – Online simulation platform (used for Verilog, SV, and I2C/UVM)
- Languages – Verilog, SystemVerilog, UVM
- Methodology – RTL Design, Testbench Architecture, Functional Verification
